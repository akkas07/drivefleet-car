# DriveFleet

A full-stack car rental website where users can browse cars, check details, book vehicles, manage their bookings, and also list their own cars for rent.

**Live Site:** [https://drivefleet-car.vercel.app](https://drivefleet-car.vercel.app)

---

## Features

- Email/Password and Google login
- JWT authentication with HTTPOnly cookies
- Users can add, update and delete their own cars
- Search and filter cars
- Booking system with notes and driver option
- Private dashboard for managing cars and bookings
- Fully responsive design
- Protected routes

---

## Tech Stack

**Frontend**
- Next.js
- Tailwind CSS
- Hero UI
- Framer Motion
- React Hot Toast

**Backend**
- Node.js
- Express.js
- MongoDB
- JWT
- Cookie Parser

## Main Functionalities

- Add car with name, price, type, image, seats, location, description
- Update and delete own car listings
- Book available cars

- Filter by car type
